# FrameWiki

FrameWiki is an Expo Router app scaffold cleaned for direct feature implementation.

## Run

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm start
```

Useful variants:

- `npm run android`
- `npm run ios`
- `npm run web`
- `npm run lint`

## Current Baseline

- File-based routing via Expo Router
- Two-tab shell under `app/(tabs)`
- Minimal Home and Explore placeholder screens
- Theme-aware UI primitives in `components/themed-*`
